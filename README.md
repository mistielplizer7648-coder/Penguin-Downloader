# Penguin Downloader

**Fast, simple download management for Windows.**

[![Get it from Microsoft](https://img.shields.io/badge/Get%20it%20from-Microsoft%20Store-0078D4?logo=microsoft)](https://apps.microsoft.com/detail/9NK598226BN3?hl=en-us&gl=US)

> **Official Microsoft Store release**  
> Product ID: `9NK598226BN3`

Penguin Downloader is a Windows download manager designed to make everyday file downloading easier to organize and manage from one place.

## Download

**Recommended:** Install the official release from Microsoft Store:

**[Download Penguin Downloader from Microsoft Store](https://apps.microsoft.com/detail/9NK598226BN3?hl=en-us&gl=US)**

Using the Microsoft Store gives you the official packaged release and the normal Windows Store installation/update experience.

## Highlights

- Windows-focused download manager
- Centralized download task management
- Pause, resume and task controls where supported
- Clean desktop interface
- Distributed through Microsoft Store
- Public issue tracker for bug reports and feedback

## Support & Feedback

Found a bug or have a feature request? Please open an issue:

**[Open an Issue](https://github.com/mistielplizer7648-coder/Penguin-Downloader/issues)**

When reporting a problem, please include your Windows version, what you were downloading, the steps to reproduce the issue, and any error message you saw. Please do not post passwords, tokens, private download links, or other sensitive information.
